Calibración de impresión

⚠️ Cómo calibrar correctamente:
1. Imprimí una página de prueba (botón abajo)
2. Superponela sobre el formulario preimpreso
3. Medí cuántos milímetros quedan desplazados los datos
4. Si el texto queda muy arriba: aumentá Y (ej: Y = +5)
5. Si el texto queda muy a la izquierda: aumentá X (ej: X = +3)
6. Si el texto sale más grande que las casillas: reducí la Escala (ej: 98%)
+ mueve a la derecha, − a la izquierda
+ mueve hacia abajo, − hacia arriba
100% = tamaño original. Ajustá si el texto no cabe en las casillas
Calibración activa: X=0mm · Y=0mm · Escala=100%

La calibración se aplica a todos los remitos de este navegador. Si usás otra computadora, tenés que calibrar de nuevo.
